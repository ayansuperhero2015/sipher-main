The lobby's material colours were also used as the palette for the generated hotel rooms.

Downloaded for this round but not wired in yet: models/nightstand.glb (Victorian Bedside Table, jamiemcfarlane),
models/chandceil.glb (Ceiling chandelier, BlackSnow02), models/mineequip.glb (Mining Equipment, VictorianBlue),
models/lantern.glb (Oil Lantern, relexy).

Only the `models/*.js` files (base64 copies of these GLBs) are included here; the game loads those.

Everything else (rooms, entities, faces, sounds) is generated in code.
