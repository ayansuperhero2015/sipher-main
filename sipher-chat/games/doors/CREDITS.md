# Credits

3D models downloaded from Sketchfab under **CC Attribution 4.0** (as labelled by the uploaders).
Most are fan uploads of models from the Roblox game DOORS (by LSPLASH), so this project is for
personal play only: do not publish or sell it.

The lobby's material colours were also used as the palette for the generated hotel rooms.

Only the `models/*.js` files (base64 copies of these GLBs) are included here; the game loads those.

Everything else (rooms, entities, faces, sounds) is generated in code.
